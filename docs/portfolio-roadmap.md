# Portfolio Engine Roadmap

1. **Shared Risk Budgets** – distribute heat/drawdown limits across concurrently held assets.
2. **Capital Allocation** – support per-asset weight targets, position blending, and rebalance triggers.
3. **Execution Policies** – batch orders, slippage models, and commission tiers.
4. **Persistence** – store run metadata (positions, risk metrics) for replay/visualisation.
5. **Scenario Testing** – plug optimised single-asset strategies into portfolio simulations to validate diversification benefits.
